# horse

One horse in full: where it is, its owners and shares, its last ten treatments with the day it is eligible again, its races, recent trackwork and every movement with its Stable Return.

Run `node scripts/stable.mjs horse <horse>`. Add `--json` when you need every field. Resolve the horse, owner, race, property or invoice by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the trainer. Never run a placeholder.

Lead with whether it can race and when. Then the plan.
