# premises

The stable, pre-training and spelling properties, each with its daily rate and how many horses are there now.

Run `node scripts/stable.mjs premises`. Add `--json` when you need every field. Resolve the horse, owner, race, property or invoice by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the trainer. Never run a placeholder.

One line per property.
