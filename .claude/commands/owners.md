# owners

Every owner with the horses they hold a share in and what they owe.

Run `node scripts/stable.mjs owners`. Add `--json` when you need every field. Resolve the horse, owner, race, property or invoice by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the trainer. Never run a placeholder.

Owners who owe first if the trainer asked about money.
