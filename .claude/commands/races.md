# races

Races coming up: planned, nominated and accepted, with nomination and acceptance deadlines on the stable clock, the jockey, the day each horse is eligible and any problem (a stand-down clash, a Stable Return not lodged, a horse not at the stable). --all includes past and scratched races.

Run `node scripts/stable.mjs races [--all]`. Add `--json` when you need every field. Resolve the horse, owner, race, property or invoice by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the trainer. Never run a placeholder.

By date. Put any problem on the first line of that race.
