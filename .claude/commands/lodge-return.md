# lodge-return

Record that the Stable Return amendment for a movement was lodged, with the reference Racing Australia gave. Only records what a person already lodged.

Run `node scripts/stable.mjs lodge-return <movement or horse> --reference=<receipt> [--at="YYYY-MM-DD HH:MM"] --actor="<you>"`. Add `--json` when you need every field. Resolve the horse, owner, race, property or invoice by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the trainer. Never run a placeholder.

Say how many hours after the move it went in.
