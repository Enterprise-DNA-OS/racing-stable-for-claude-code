# set

Change a house rule or stable setting: stable_name, zone, gst_bps, invoice_days, update_days, return_hours, work_gap_days or spell_days.

Run `node scripts/stable.mjs set <key> <value> --actor="<you>"`. Add `--json` when you need every field. Resolve the horse, owner, race, property or invoice by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the trainer. Never run a placeholder.

Say the old and new value.
