# horses

Every horse in the stable, in work first, then pre-training and spelling: age on the 1 August birthday, where it is and since when, owners and shares, any stand-down, last fast work, next race and last owner update. --all includes horses that have left.

Run `node scripts/stable.mjs horses [--all]`. Add `--json` when you need every field. Resolve the horse, owner, race, property or invoice by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the trainer. Never run a placeholder.

Group by status. Flag a shares total that is not 100 and any stand-down.
