# debtors

What each owner owes, split into not yet due, 1 to 30 days late and over 30 days late.

Run `node scripts/stable.mjs debtors`. Add `--json` when you need every field. Resolve the horse, owner, race, property or invoice by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the trainer. Never run a placeholder.

Largest first. Offer draft-chaser for each late owner.
