# update

Record that the owners of a horse were sent an update, with a one-line summary.

Run `node scripts/stable.mjs update <horse> --summary="<what they were told>" [--on=YYYY-MM-DD] --actor="<you>"`. Add `--json` when you need every field. Resolve the horse, owner, race, property or invoice by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the trainer. Never run a placeholder.

One line back.
