# draft-chaser

Draft a polite note to an owner listing their unpaid invoices and the total. Written to drafts/, never sent.

Run `node scripts/stable.mjs draft-chaser <owner>`. Add `--json` when you need every field. Resolve the horse, owner, race, property or invoice by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the trainer. Never run a placeholder.
