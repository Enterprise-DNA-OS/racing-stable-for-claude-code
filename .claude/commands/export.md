# export

Export every record to one JSON file the stable owns.

Run `node scripts/stable.mjs export [--out=<file>]`. Add `--json` when you need every field. Resolve the horse, owner, race, property or invoice by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the trainer. Never run a placeholder.

Give the file path.
