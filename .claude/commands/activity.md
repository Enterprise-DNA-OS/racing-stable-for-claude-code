# activity

The activity log: who did what, newest first. --days=N rows (default 30).

Run `node scripts/stable.mjs activity [--days=N]`. Add `--json` when you need every field. Resolve the horse, owner, race, property or invoice by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the trainer. Never run a placeholder.

Newest first.
