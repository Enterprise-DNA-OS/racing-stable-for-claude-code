# owner

One owner in full: their shares (past and present) and every invoice with what is still owing.

Run `node scripts/stable.mjs owner <owner>`. Add `--json` when you need every field. Resolve the horse, owner, race, property or invoice by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the trainer. Never run a placeholder.

Lead with what they owe and how late.
