# scratch

Scratch a horse from a race, with the reason.

Run `node scripts/stable.mjs scratch <race ref> --reason="<why>" --actor="<you>"`. Add `--json` when you need every field. Resolve the horse, owner, race, property or invoice by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the trainer. Never run a placeholder.

Remind them to tell the Stewards and the owners.
